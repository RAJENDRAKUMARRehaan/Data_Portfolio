### Manchester City – Tableau de bord de performance (2016–2025)

Création d’un tableau de bord interactif sous Power BI analysant les performances de Manchester City durant l’ère Pep Guardiola.

**Contenu du projet :**
- Analyse offensive (buteurs, passeurs, efficacité par match)
- Analyse défensive (buts encaissés, stabilité défensive, variabilité)
- Indicateurs dynamiques (KPI) créés en DAX
- Visualisations avancées (scatter plot, boxplot, stacked charts)
